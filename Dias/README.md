# Dias Safari Lodge Starter

This is a fresh project folder for a new safari lodge website.

## How to use

1. Open the `Dias` folder in VS Code.
2. Edit `index.html`, `assets/css/styles.css`, and `assets/js/main.js`.
3. Save your files.
4. Open `index.html` with Live Server or open it directly in your browser.
